<h1 align="center">Infinity New Tab</h1>

<p align="center">Apple 风格的 Chrome 新标签页：壁纸占满整屏，书签像目录一样排在底部，搜索栏直接输入，按钮是会折射背景的 Liquid Glass。</p>

<p align="center"><strong>TypeScript · 原生 Web Components · SVG Refraction · WebGPU HDR</strong></p>

Infinity New Tab 不依赖前端框架。页面组件、数据层、光学位移图和 HDR 边缘光层均在扩展内部运行，旧版备份可以直接导入。

## 亮点

| 书签 | 视觉 | 数据 |
| --- | --- | --- |
| 全部书签按文件夹排在底部，中间留给壁纸 | 每个玻璃按钮按自身形状折射背景 | Chrome 同步存储（自动分片） |
| 搜索栏直接输入，建议就在下方展开 | WebGPU HDR 边缘高光 | 兼容 1.0 / 2.0 备份 |
| 按需出现的媒体、下载与电量胶囊 | 内置动态壁纸，静止时只留时间 | 危险 URL 清洗与去重 |

## 功能

- **主屏**：默认壁纸是内置的动态场景 Twilight Bay（纯 SVG，不占存储）。左上角是日期、时间和搜索栏，全部书签排在屏幕底部，画面中间不放任何东西；右上角是状态胶囊（只在播放媒体、下载或使用电池时出现）、“换一个在线壁纸”和设置。
- **静止时只留时间**：8 秒无操作后界面淡出，只保留时间；移动鼠标或按键立即恢复（可在“设置 → 壁纸 → 播放”关闭）。
- **搜索**：直接在左上角的搜索栏里输入，不再弹出单独的窗口；`⌘K`（Windows 为 `Ctrl K`）或 `/` 把光标放进搜索栏，关闭搜索栏后这个快捷键会临时把它叫出来。建议列表在输入框正下方展开，同时给出书签、常访问网站、网页搜索和最近搜索；输入网址可直接打开，首个结果会在输入框内补全域名（按 → 接受）。方向键选择，有内容时 Tab 或点右侧的引擎名切换搜索引擎，Esc 先清空再退出。
- **书签**：像目录一样排在屏幕底部，每个文件夹一组，只有文字和 16px 网站图标，不用切换标签或翻页。书签多时每组自动加行，最多占屏幕高度的 40%，再多就横向滚动（鼠标滚轮也可以），边缘渐隐提示还有更多；底部一层很淡的渐暗让文字在任何壁纸上都看得清。悬停分组标题会出现“+”（添加到这一组）和“⋯”（重命名、删除、新建文件夹）；把书签拖到分组上即可移动，拖到另一个书签上会排到它前面；右键（或键盘 Shift+F10）可编辑、移动、删除。开启“常访问网站”后，最后一组是最近 30 天最常去的 8 个网站。只存了网址的书签显示网站名而不是域名，例如 `www.github.com` 显示为 GitHub。
- **设置**：仿 macOS 系统设置的窗口，左侧是带彩色图标的外观 / 组件 / 壁纸 / 数据，右侧是分组的设置行，左上角红点关闭；搜索框可跨分类查找设置项。开关、滑块和分段控件都按 macOS 样式重做，分段控件的选中块会滑到新选项下。
  - 外观：文字颜色（自动 / 浅色 / 深色）、玻璃材质（清透 / 着色）、HDR 高光、降低透明度、时间与日期格式。
  - 组件：时间、搜索栏、书签、状态胶囊的开关；常访问网站、在新标签页打开书签；默认搜索引擎、是否保存最近搜索。
  - 壁纸：本地图片 / 循环视频 / 在线壁纸、模糊与暗化；使用电池或标签页不可见时自动暂停动态壁纸，可选播放视频声音。
  - 数据：同步空间与本地媒体用量、导入导出备份、每月备份提醒、清空所有数据。
- 在线壁纸下载后存入 IndexedDB，之后每次打开新标签页都是同一张，不再闪烁。
- 所有确认、输入与提示都使用页面内对话框和 macOS 样式的右键菜单，Esc 可关闭，焦点不会跑到背景。
- 书签与设置存入 `chrome.storage.sync`（书签自动拆分为多个不超过 8 KB 的分片），本地媒体存入 IndexedDB；媒体保存或播放失败会明确提示并保留原背景。
- 同时打开多个新标签页，或在另一台设备上修改时，各页面会自动载入最新数据，后保存的页面不会覆盖先保存的修改。
- 输入 `localhost:3000`、`192.168.1.1:8080`、`nas.local` 这类本地地址时默认使用 `http://`，其他网址默认 `https://`。

## HDR 显示

- “设置 → 外观 → HDR 高光”默认开启，并显示当前屏幕是否支持真实 HDR 输出。
- 在 HDR 屏幕与兼容 Chrome 上，一个覆盖整窗、不接收点击的 WebGPU 画布（`rgba16float`、`extended` 色调映射）为每个可见的玻璃按钮画一圈 1.25px 的边缘光：迎光的左上沿最亮，指针靠近的那一段会亮到 SDR 白色以上。
- 边缘按圆角矩形的距离场在屏幕像素上逐点计算并抗锯齿，不再把小画布拉伸到控件上；指针位置和亮度变化都做了平滑，被设置窗口、对话框遮住或正在淡出的按钮不会画边缘光。
- 普通 SDR 屏幕不创建 GPU 设备，玻璃边缘由 CSS 绘制；本地 HDR 图片或视频保持原始动态范围。

## Liquid Glass

折射算法沿用 [Liquid Glass in the Browser: Refraction with CSS and SVG](https://kube.io/blog/liquid-glass-css-svg/)，但不再用一块在组件之间跳动的共享镜片：

- 每个放在壁纸上的玻璃控件（搜索栏、右上角按钮、状态胶囊、暂停按钮）都是一块独立的玻璃。玻璃系统按控件的实际宽高和圆角生成 SVG 滤镜，作为它自己的 `backdrop-filter`，背景只在控件边缘发生弯折。
- 位移场使用文章的凸面 squircle、折射率 `1.5`、Snell 折射和 128 个径向取样，按 `R = 128 + x × 127`、`G = 128 + y × 127` 编码；尺寸和圆角相同的控件共用同一个滤镜。
- 指针下方有一团跟随移动的柔光，悬停时淡入、离开时淡出；按下时控件以弹簧曲线轻微缩小。控件之间移动时没有任何形变或跳动。
- 菜单、对话框、设置窗口和搜索建议使用更安静的磨砂面板，不做折射。

SVG `backdrop-filter` 按文章说明仅保证 Chromium/Chrome 可用。

## 性能设计

- 设置窗口的四个分类只在首次挂载时构建一次；打开、关闭、切换分类或保存设置都不会重建控件。
- 折射位移图按尺寸、圆角和像素密度缓存，形状相同的控件共用一个 SVG 滤镜。
- 数据变更按 `bookmarks`、`folders`、`settings.appearance`、`settings.wallpaper`、`settings.layout` 等范围分发，修改滑块不会刷新书签、历史记录或系统状态。
- HDR 边缘光只有一个画布和一次绘制；只在指针移动、窗口变化或界面切换后的片刻内逐帧更新，静止时不占用 GPU。

## 数据导入与导出

设置 → 数据提供：

- 导出 `2.0` JSON：包含同步数据及本地图片/视频壁纸。
- 导入旧版 `1.0` 或新版 `2.0` JSON。
- 自动补齐旧备份缺少的状态栏、常访问、主题等设置。
- 自动合并同一文件夹中完全相同的网址（只有查询串不同的网址视为不同页面），拒绝 `javascript:` 等危险 URL。
- 导入会覆盖当前扩展数据，建议先导出一份备份。

此前使用的 `bookmarks`、`folders`、`settings`、`recentSearches` 与 `lastBackupPrompt` 数据键继续兼容。早已没有界面的待办（`todos`）不再导入或导出，导入备份时会从同步存储中清除。

## 安装

1. 在项目目录构建 TypeScript：

   ```bash
   npm install
   npm run build
   ```

2. 打开 `chrome://extensions` 并启用开发者模式。
3. 点击“加载已解压的扩展程序”，选择本项目目录。
4. 已经加载过时，点击扩展卡片上的“重新加载”，再打开新标签页。

设置窗口左下角显示当前版本号（取自 `manifest.json`）。

### 运行要求

- Chrome 120 或更高版本。
- Liquid Glass 的 SVG `backdrop-filter` 以 Chromium 为目标。
- 真正超过 SDR 白色亮度的高光需要 HDR 显示器、WebGPU 和 Chrome 的 extended tone mapping；其他环境自动回退到 SDR。

## 开发与验证

```bash
npm run build
npm run typecheck
npm test
```

自动化测试不读取日常 Chrome 数据，覆盖：

- 旧版备份清洗与迁移。
- 危险 URL 过滤与同步写入失败回滚。
- 书签拖入文件夹和同文件夹排序不复制。
- 每个玻璃控件都有与自身尺寸一致的折射滤镜，指针柔光跟随位置；模拟 HDR 屏幕时，WebGPU 只为未被遮挡的玻璃画边缘光。
- 有界面的 Chrome 中开启与关闭折射的像素必须不同，防止只改变参数却没有画面效果；无界面 Chrome 不合成 SVG `backdrop-filter`，因此界面回归固定使用有界面模式。
- 设置、本地壁纸、导入、导出和备份提醒布局。
- 大量书签的同步分片与旧单键数据迁移，过大内嵌图标拒绝写入。
- 时间在左上角、书签目录在底部，画面中间不被遮挡，页面不出现滚动。
- 设置与弹窗的 Esc 关闭、焦点陷阱和焦点归还；右键菜单移动、文件夹新建 / 重命名 / 删除全程不出现浏览器原生对话框。
- 搜索栏的就地输入、书签匹配、域名补全、网址识别、键盘选择、引擎切换、最近搜索删除和隐藏时用快捷键叫出；书签显示网站名；设置跨分类搜索；静止时淡出。
- 本地壁纸覆盖 IndexedDB 保存失败回滚、原生视频播放失败提示以及刷新后恢复。

仓库不保存界面截图或截图基线；折射回归在测试运行时进行内存像素比较，不产生图片文件。

## 权限与隐私

- `storage`：同步书签与设置。
- `history`：仅在本机统计最近常访问的网站。
- `tabs`：识别正在播放媒体的标签页并支持跳转。
- `downloads`：显示进行中的下载。
- `favicon`：使用 Chrome 本地 favicon 接口获取图标。
- `https://www.dmoe.cc/*`（主机权限）：下载随机壁纸并缓存到本地。该站点不返回 CORS 头，需要此权限才能保存图片。

扩展不会把浏览历史发送给第三方图标服务。随机二次元壁纸依赖 `dmoe.cc` 的可用性；下载后的图片只保存在本机。

### 3.0.0 - 2026-10-12

- 按 Apple 风格重新设计全部界面。Liquid Glass 改为每个控件各自折射背景，去掉在组件之间跳动、拉伸的共享镜片；HDR 边缘光改为整窗 WebGPU 层按屏幕像素绘制，不再出现锯齿和拉伸。

- 主屏改为壁纸优先：时间和搜索栏移到左上角，全部书签按文件夹排成底部的文字目录（16px 网站图标，没有图标底板），画面中间留给壁纸；不再有 Dock、全屏启动台和 Dock 大小 / 放大设置，书签搜索在搜索栏里完成。备份提醒移到右上角。

- 只存了网址的书签和常访问网站显示网站名（GitHub、V2EX、Hacker News），不再显示带后缀的域名。
- 状态改为右上角胶囊：正在播放的标签页显示网站图标与均衡器，可一键静音。
- 设置改为仿 macOS 系统设置的窗口，侧栏使用彩色图标，开关、滑块、分段控件、对话框和右键菜单统一为 macOS 样式，可跨分类搜索；新增玻璃材质、降低透明度、保存最近搜索、电池与后台自动暂停、视频声音、存储用量显示；备份提醒改为每月一次并可关闭。
- 壁纸模糊范围扩大到 40px，暗化上限调整为 60%（更高的旧值会降到 60%）。
