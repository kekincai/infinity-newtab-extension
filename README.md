# Infinity New Tab Extension 🚀

一个功能丰富、界面精美的 Chrome 新标签页扩展，让你的每一次打开新标签都成为愉悦的体验。

## ✨ 主要功能

### 🖼️ 壁纸系统
- **本地上传**：支持上传任意图片作为背景
- **本地视频**：支持上传本地视频作为动态壁纸（静音/循环/自动播放）
- **二次元壁纸**：可一键从二次元壁纸站拉取随机背景
- **自定义调节**：
  - 可调节模糊度（0-10px）
  - 可调节暗度覆盖层（0-80%）
- **一键重置**：恢复默认渐变背景

### 🔍 智能搜索
- **多引擎支持**：Google、Bing、百度、DuckDuckGo
- **快捷键**：按 `/` 立即聚焦搜索框
- **引擎切换**：在设置中一键切换
- **液态玻璃搜索框**：折射、流动高光与清晰的聚焦反馈

### 📊 状态概览
- **活动监测**：正在播放的媒体标签、进行中的下载
- **系统信息**：CPU 线程数、设备内存、可用时显示电池状态

### 🧭 最近常访问
- **常用网站聚合**：自动提取近期常访问的网站，横向滑动浏览
- **隐私保护**：网站图标由 Chrome 本地 favicon 接口提供，不会把历史域名发送给图标服务

### 🔖 增强的书签管理
- **文件夹分类**：更好地组织你的书签
- **自动获取图标**：使用 Chrome 本地 favicon 接口获取网站图标
- **快速访问**：点击书签在新标签页打开
- **悬停删除**：悬停显示删除按钮
- **拖拽整理**：书签可排序，也可拖入文件夹
- **文件夹管理**：悬停后可重命名或删除文件夹
- **启动台视图**：像 macOS Launchpad 一样的文件夹卡片浏览

### ⚙️ 强大的设置面板
侧边滑出式设置面板，包含4个选项卡：

#### 1. 外观
- 时钟格式（12/24小时制）
- 搜索引擎选择

#### 2. 壁纸
- 随机壁纸
- 上传本地图片
- 重置默认背景
- 模糊度调节
- 暗度调节

#### 3. 布局
显示/隐藏组件开关：
- 时钟
- 搜索框
- 书签
- 状态概览
- 最近常访问

#### 4. 数据
- **导出数据**：将所有设置和数据导出为 JSON
- **导入数据**：从 JSON 文件恢复数据，兼容旧版 `1.0` 备份
- **媒体备份**：新版 `2.0` 备份会包含本地图片与视频壁纸
- **重置设置**：一键恢复默认设置

### 💾 数据同步
书签和设置使用 `chrome.storage.sync`，本地图片与视频使用 IndexedDB：
- 自动保存所有设置
- 跨设备同步（同一 Chrome 账号）
- 本地媒体不占用同步存储配额

## 🎨 设计特色

- **Liquid Glass 视觉系统**：透明材质、边缘高光、背景折射和糖果色光泽统一覆盖主要组件
- **真实折射与降级**：Chromium 中使用 SVG 位移滤镜，移动端、低动态偏好或关闭增强动画时自动使用轻量毛玻璃
- **流动光标高光**：增强动画开启后，高光会随指针在玻璃表面移动
- **共享液态按钮**：同一块玻璃选中层会在相邻按钮之间拉伸、流动并回弹，不产生额外的悬浮镜片
- **响应式设计**：桌面与手机分别调整折射强度、尺寸和触控操作
- **直观操作**：悬停显示控制按钮，减少视觉杂乱

## 📦 安装方法

### 从源码安装（开发者模式）

1. **下载代码**
   ```bash
   cd /Users/kejincai/dev/infinity-newtab-extension
   ```

2. **打开 Chrome 扩展页面**
   - 在地址栏输入 `chrome://extensions`
   - 或通过菜单：更多工具 → 扩展程序

3. **启用开发者模式**
   - 点击页面右上角的"开发者模式"开关

4. **加载扩展**
   - 点击"加载已解压的扩展程序"
   - 选择项目目录
   - 点击"选择"

5. **开始使用**
   - 打开新标签页（Cmd+T 或 Ctrl+T）
   - 享受全新的标签页体验！

## 🔧 技术栈

- **原生技术**：HTML、CSS、JavaScript (ES6+)
- **Chrome API**：
  - `chrome.storage.sync`：数据持久化和同步
  - `chrome.history`：生成最近常访问列表
  - `chrome.tabs` / `chrome.downloads`：显示活动概览
  - `chrome.favicon`：在本地读取网站图标
  - `chrome_url_overrides`：新标签页覆盖
- **架构模式**：模块化单例模式
- **设计**：Liquid Glass（SVG 折射 + CSS 边缘高光 + 模糊降级）

## 🔐 权限与隐私

- `history`：仅用于在本机统计最近常访问的网站。
- `tabs`：仅用于识别正在播放媒体的标签页并支持跳转。
- `downloads`：仅用于显示进行中的下载。
- `favicon`：仅通过 Chrome 本地接口显示网站图标。
- 扩展不会把浏览历史上传到第三方图标服务。

## 🐛 已知限制

1. **同步配额**：书签和设置受 `chrome.storage.sync` 配额约束；本地壁纸不参与同步。
2. **远程壁纸**：随机二次元壁纸依赖第三方服务的可用性；失败时会保留当前背景。
3. **浏览器兼容**：仅支持 Chromium 内核浏览器（Chrome、Edge 等）。
