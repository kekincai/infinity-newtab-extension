## 安装

需要 Chrome 120 或更高版本。

**从 Release 安装**

1. 在 [Releases](https://github.com/kekincai/infinity-newtab-extension/releases) 下载最新的 `infinity-newtab-extension-<版本>.zip` 并解压。
2. 打开 `chrome://extensions`，打开右上角的“开发者模式”。
3. 点“加载已解压的扩展程序”，选择解压出的文件夹。

**从源码安装**

克隆仓库后按上面第 2、3 步选择仓库目录即可。仓库里已经带有构建好的 `modules/app.js`，不需要先构建。

**更新**

拿到新代码（重新解压或 `git pull`）后，在 `chrome://extensions` 点扩展卡片上的“重新加载”，再打开新标签页。不需要删除后重新导入，书签和设置都在。当前版本号显示在设置窗口左下角。

## 使用

### 主屏

- 默认壁纸是内置的动态场景 Twilight Bay（纯 SVG，不占存储）。
- 左上角是日期、时间和搜索栏，书签排在屏幕底部，画面中间留给壁纸。
- 右上角是状态胶囊、“换一个在线壁纸”和设置。状态胶囊只在有标签页播放声音（可一键静音或跳转）、有文件在下载、或笔记本使用电池时出现。
- 8 秒没有操作时界面淡出，只留时间；动一下鼠标或按任意键就回来。可以在“设置 → 壁纸 → 播放”关闭。
- 动态壁纸右下角有暂停按钮。

### 书签

- 所有书签同时显示在底部：没有放进文件夹的一组，每个文件夹各一组，每条只有网站图标和名字。
- 书签多时每组自动加行，最多占屏幕高度的 40%，再多就横向滚动（鼠标滚轮也可以）。
- 只存了网址的书签显示网站名，例如 `www.github.com` 显示为 GitHub。
- 鼠标移到分组标题上会出现“+”（添加书签）和“⋯”（重命名、删除文件夹、新建文件夹）。
- 把书签拖到另一组上就移过去；拖到某个书签上就排到它前面。
- 右键书签（或用键盘按 `Shift+F10`）可以编辑、移动到文件夹、删除。
- 打开“常访问网站”后，最后一组是本机最近 30 天最常去的 8 个网站，右键可以加为书签。

### 搜索

- 直接在左上角的搜索栏里输入，建议列表在下方展开：网址、书签、常访问网站、网页搜索、最近搜索。
- 输入网址可以直接打开。不写协议时，`localhost:3000`、`192.168.1.1:8080`、`nas.local` 这类本地地址用 `http://`，其他网址用 `https://`。
- 第一条结果是书签或常访问网站时，输入框里会补全域名，按 `→` 接受。
- 搜索栏在设置里关掉后，快捷键仍然能把它临时叫出来。

### 壁纸

在“设置 → 壁纸”里更换：

- **本地图片或视频**：点“选择视频或图片…”；也可以把照片或视频直接拖到壁纸卡片上，或者复制后按 `⌘V`（Windows 为 `Ctrl+V`）粘贴。
- **在线壁纸**：点“换一个在线壁纸”（主屏右上角也有），从 `dmoe.cc` 随机下载一张二次元图片。
- **恢复默认**：回到 Twilight Bay，并删除保存的图片和视频。

选好的图片和视频保存在本机，每次打开新标签页都是同一张，不会重新下载。还可以调模糊和暗化（让白色文字在亮壁纸上更清楚），以及设定使用电池、标签页不可见时暂停动态壁纸，播放视频声音。

**用“照片”App 里的照片（包括隐藏相簿）**

Chrome 扩展打不开 macOS 的照片选择器，可以这样做：

1. 在“照片”App 里打开照片；隐藏的照片先在“已隐藏”相簿里用 Touch ID 或密码解锁。
2. 把照片拖到壁纸卡片上，或选中后按 `⌘C`，回到壁纸设置按 `⌘V`。

Chrome 显示不了 HEIC 格式。如果拖进来的是 HEIC 原图，会提示你改用复制粘贴，或者在“照片”里用“文件 → 导出”存成 JPEG。

### 设置

点右上角的齿轮打开，左上角红点或 `Esc` 关闭。左侧搜索框可以跨分类查找设置项。

| 分类 | 内容 |
| --- | --- |
| 外观 | 文字颜色（自动 / 浅色 / 深色）、玻璃材质（清透 / 着色）、HDR 高光、降低透明度、时钟与日期格式 |
| 组件 | 时间、搜索栏、书签、状态胶囊的开关；常访问网站；在新标签页打开书签；默认搜索引擎；保存最近搜索 |
| 壁纸 | 更换壁纸、模糊、暗化；静止时隐藏界面；使用电池或标签页不可见时暂停；视频声音 |
| 数据 | 同步空间与本地媒体用量；导出、导入备份；每月备份提醒；清空所有数据 |

“自动”文字颜色会根据壁纸明暗选择浅色或深色文字。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `⌘K` / `Ctrl K`、`/` | 把光标放进搜索栏；在搜索栏里再按 `⌘K` 离开 |
| `↑` `↓` | 在搜索建议中选择 |
| `Enter` | 打开选中的结果 |
| `⌘` / `Ctrl` + `Enter`，或按住 `⌘` / `Ctrl` 点击 | 在新标签页打开，留在当前页 |
| `Tab` | 有输入内容时切换搜索引擎 |
| `→` | 接受补全的域名 |
| `Esc` | 先清空搜索栏，再按一次退出；关闭对话框、菜单和设置 |
| `Shift+F10` | 打开书签的右键菜单 |

## 数据与同步

- 书签、文件夹、设置和最近搜索保存在 `chrome.storage.sync`，登录同一 Chrome 账号的设备之间会同步。Chrome 给扩展的同步空间约 100 KB，用量显示在“设置 → 数据”。书签会自动拆成多个不超过 8 KB 的分片保存。
- 壁纸图片和视频只保存在本机（IndexedDB），不占同步空间，也不会同步到其他设备。
- 同时开着几个新标签页，或在另一台设备上改了书签时，各页面会自动载入最新数据，不会互相覆盖。
- 保存失败（比如同步空间满了、壁纸文件无法播放）会明确提示，并保留原来的数据和背景。

**备份**

在“设置 → 数据”里：

- **导出**：一个 JSON 文件（2.0 格式），包含书签、设置和本地的壁纸图片、视频。
- **导入**：支持 1.0 和 2.0 格式，会覆盖当前数据，建议先导出一份。旧备份缺少的设置会自动补上默认值；同一文件夹里网址完全相同的书签会合并；`javascript:` 等不安全的网址会被丢弃。导入失败时，原来的壁纸会恢复。
- 开着“每月提醒我备份”时，距上次备份满一个月会在右上角提醒一次。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存并同步书签与设置 |
| `history` | 在本机统计最近 30 天常访问的网站 |
| `tabs` | 找到正在播放声音的标签页，支持跳转和静音 |
| `downloads` | 显示正在进行的下载 |
| `favicon` | 通过 Chrome 本地接口获取网站图标 |
| `https://www.dmoe.cc/*` | 下载随机二次元壁纸。该站点不返回 CORS 头，需要这个权限才能把图片保存到本机 |

浏览记录、书签和壁纸都不会发送给第三方。只有换在线壁纸时才会访问 `dmoe.cc`（2.5 之前的版本存的是随机图片地址，升级后第一次打开时也会下载一张）；下载的图片只保存在本机，在线壁纸是否可用取决于该站点。

## 技术说明

整个扩展不依赖前端框架：页面由原生 Web Components 组成，状态、存储、备份和光学计算都是 TypeScript，构建成一个 `modules/app.js`。

### Liquid Glass

折射算法基于 [Liquid Glass in the Browser: Refraction with CSS and SVG](https://kube.io/blog/liquid-glass-css-svg/)。

- 主屏上的每个玻璃控件（搜索栏、右上角按钮、状态胶囊、暂停按钮）都是一块独立的玻璃：按它的实际宽高和圆角生成一个 SVG 滤镜，作为它自己的 `backdrop-filter`，背景只在边缘弯折。
- 位移场使用凸面 squircle、折射率 `1.5`、Snell 折射和 128 个径向取样，编码为 `R = 128 + x × 127`、`G = 128 + y × 127`。尺寸和圆角相同的控件共用一个滤镜，不再使用的滤镜会被回收。
- 指针下有一团跟随的柔光，悬停时淡入；按下时控件以弹簧曲线轻微缩小。
- 菜单、对话框、设置窗口和搜索建议用的是不折射的磨砂面板。
- SVG `backdrop-filter` 只在 Chromium 内核的浏览器上可用。

### HDR 边缘光

- “设置 → 外观 → HDR 高光”默认开启，并显示当前屏幕是否支持 HDR、WebGPU 是否已启用。
- 在 HDR 屏幕上，一个覆盖整个窗口、不接收点击的 WebGPU 画布（`rgba16float`、`extended` 色调映射）为每个可见的玻璃控件画一圈 1.25px 的边缘光：迎光的左上沿最亮，指针附近的一段会亮过 SDR 白色。
- 边缘按圆角矩形距离场逐像素计算并抗锯齿；被设置窗口、对话框遮住或正在淡出的控件不画。
- 普通屏幕不创建 GPU 设备，玻璃边缘由 CSS 绘制。本地 HDR 图片和视频保持原始动态范围。

### 性能

- 设置窗口的四个分类只在第一次挂载时构建，之后打开、关闭、切换或保存都只同步控件状态。
- 数据变更按 `bookmarks`、`folders`、`settings.appearance`、`settings.wallpaper`、`settings.layout` 等范围通知，拖动滑块不会重绘书签或状态胶囊。
- HDR 边缘光只有一个画布；只在指针移动、窗口变化或界面变化后的片刻内逐帧更新，静止时不占用 GPU。指针移动时复用已测量的位置，不重新测量所有控件。
- 网站图标按实际显示尺寸加载。

## 开发

```bash
npm install
npm run build       # 构建 modules/app.js
npm run typecheck   # 类型检查（包括测试代码）
npm test            # 构建 + 类型检查 + 单元测试 + 界面测试
```

- `modules/app.js` 是构建产物，但要提交到仓库，因为 Chrome 直接加载它。改完 `src/` 后记得 `npm run build` 并一起提交。
- 界面测试（`npm run test:e2e`）用 Playwright 驱动有界面的 Chrome，会弹出浏览器窗口：无界面 Chrome 不合成 SVG `backdrop-filter`，折射测试需要比较真实像素。测试会占用 4173 端口，运行前要先停掉同端口的本地预览服务。
- 测试不读取日常 Chrome 数据，输出都在被忽略的 `test-results/` 目录，不保存截图基线。

**测试覆盖**

- 单元测试（`tests/unit-entry.ts`）：备份清洗与旧版迁移、危险网址过滤、网址补全协议、书签分片与清理、写入失败回滚、多个标签页之间的同步不互相覆盖、常访问网站排序与命名、折射位移场。
- 界面测试（`tests/e2e/`）：主屏布局、玻璃折射与 HDR 边缘光、书签拖放与右键菜单、设置的保存与跨分类搜索、壁纸上传、拖放、粘贴与失败回滚、备份导入导出、搜索栏交互、键盘与焦点、静止淡出。
